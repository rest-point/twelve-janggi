첫 행동의 네 합법 선택지를 각각 시험했다. 원본 v2로 이후 수를 두었을 때 `lab-opening-v1`부터 v4의 승/무/패는 각각 **0/4/0, 0/3/1, 0/2/2, 0/3/1**이었다. 모든 기보를 재검증했고 모델 실패는 0건이다. 이들 중 성과가 개선됐다고 채택한 모델은 없다.

통제 대전의 합법 수순에서 중반 한 수만 바꾸고 원본 정책으로 종국까지 진행한 128개 분기도 검사했다. 탐색한 분기 기준 **0승 68무 60패**, 모델 실패 0건이며 모든 기보를 심판 엔진으로 재검증했다. 이것은 중간 국면에서 시작하는 연구용 재대국으로 웹 100국 통계와 합산하지 않는다. 한 수만 바꾸는 국소 탐색에서 승리를 찾지 못했다는 결과이며 상대의 최적성 증명은 아니다.

### 압축 상태 기반의 새 알파베타 후보

`lab-fast-search-v1`은 StockJang과 비슷한 기물/왕 안전 평가를 사용하고, 기존 검증된 `azero-core.mjs`의 압축 상태·합법수·전이를 재사용하는 새 알파베타 탐색이다. 초기 이력을 유지하고 점수 캐시에는 탐색 경로의 국면별 등장 횟수를 정확히 반영한다. 배치 256수 제한은 심판에 맡겨 사람 대국의 256수 이후 국면도 합법 수를 반환한다.

## 4. 실제 웹 검증과 후속 평가

`lab-neural-v2`의 코드·가중치·설정을 artifact `5fc3de8a94fc6237031e608f1cbbfbecbd68cb8f61f84cd2d05643629fb809f7`로 고정했다. [실제 웹 100국 페이지](http://127.0.0.1:3000/experiments?run=8aad2758-b524-40ea-94b5-887fcd045b03)에서 같은 상대와 대전 중이다. 첫 네 조건의 4전 전승은 실제 웹에서 유지되지 않았으며, 결과는 완료된 100국과 별도 기보 재검증 후 확정한다.

웹 검증이 끝나면 조정에 사용하지 않은 seed `20261201`·임의 합법 오프닝 4수·12국을 기준 도전자와 최종 후보에 똑같이 적용한다. 전체 절대 256수 한도를 맞추기 위해 이후 대국 수는 최대 252수다. 추가로 AlphaZero v1과 StockJang에 각 4국을 실행한다. `finish-winrate-campaign.mjs`가 웹 100국의 전체 검증 완료를 기다린 뒤 순서대로 진행하며, 각 단계에서 모델 해시 고정을 확인한다.

[모델 구성과 한계](LAB_NEURAL_MODEL.md)에 탐색 방식, 반복 이력, 계산 예산, 재현 방법을 정리했다.

## 재현 명령

```powershell
# 서버용 .env와 별도 실험 DB를 준비한 본 작업 폴더 기준
node server/start.mjs

# 별도 터미널: 완료된 조합은 재사용하는 144국 선별
node scripts/winrate-campaign.mjs --stage screening --games 4

# 고정 상대에 대해 준비한 세 후보를 각각 4국 비교
node scripts/winrate-campaign.mjs --stage candidates --b azero-v2 --games 4

# 웹 100국: 같은 label로 재실행하면 기존 requestId/배치에서 재개
node scripts/winrate-web.mjs greedy-v1 random-v1 pipeline-check
```

연속 실행 중 동일 label을 다른 조합에 재사용하면 거부한다. 세션 파일은 Git에서 제외되는 `data/`에 보관하고 보고서에는 포함하지 않는다.
