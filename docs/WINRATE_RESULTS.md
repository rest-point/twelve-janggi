### 별도 오프닝의 동일 국면 비교

조정에 사용하지 않은 seed `20261201`·임의 합법 오프닝 4수·12국을 기준 도전자와 최종 후보에 똑같이 적용했다. 전체 절대 256수 한도를 맞추기 위해 이후 대국 수는 최대 252수다. 두 실행의 시작 상태·오프닝·모델 진영 배정이 12국 모두 같은 것을 별도로 확인했다. 서로 다른 시작 국면은 6개이며 각 국면에서 진영을 교환했다.

| 도전자 (상대는 원본 `azero-v2`) | 승 | 무 | 패 | 승률 | 득점률 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 기준 `azero-v1` | 2 | 4 | 6 | 16.667% | 33.333% |
| 최종 `lab-neural-v2` | 5 | 4 | 3 | 41.667% | 58.333% |

관측 승률과 득점률은 각각 **25%포인트 증가**했다. 동일 배정별 변화는 패→승 2국, 무→승 1국, 승→승 2국, 패→패 2국, 무→무 2국, 패→무 2국, 무→패 1국이다. 모든 기보·시간·실행 요약 검증을 통과했고 모델 실패는 없다. 최종 후보를 고정한 뒤 측정했으며 이 결과를 이용해 다시 조정하지 않았다.

이는 6개 국면의 작은 별도 점검이다. 후보 승률이 50% 미만이므로 **이 오프닝 묶음에서 상대보다 우세하다는 목표는 미달**이다. 초기 국면 웹 100국의 72%를 임의 국면 전체의 승률로 확대하지 않는다. 실행 원본은 `holdout-baseline.json`, `holdout-candidate.json`이 가리키는 각 `artifacts/<run-id>/`에 있다.

## 5. 채택 결론과 남은 검증

원본 리그 선두 `azero-v2`를 고정한 첫 캠페인에서 `lab-neural-v2`를 개선 후보로 채택한다. 네 초기 조건의 선별에서 기준 도전자는 0승 2무 2패, 후보는 4승이었고, 후보의 별도 실제 웹 100국은 72승 22무 6패였다. 더 강한 일반화 근거로 쓰기에는 작지만, 조정에 사용하지 않은 동일 오프닝 비교에서도 기준 도전자보다 승리가 3국 증가했다. 이 세 결과의 대국 수·실행 경로·시작 조건을 합치거나 직접 동일 표본처럼 해석하지 않는다.

계산량을 맞춘 알고리즘 비교와 기준 도전자의 별도 웹 100국은 이번에 실행하지 않았다. 대신 실제 착수시간을 공개하고, 별도 12국을 양 도전자에게 같은 국면·배정으로 적용했다. 향후 동일 시간 예산 후보 비교, 더 다양한 별도 오프닝, 장비 부하별 반복 측정, 다른 상위 상대의 충분한 대국 수가 필요하다. 새 가중치 학습은 수행하지 않았다.

실제 기록은 일반 CLI 대국 240국, 중반 단일 분기 연구 128건, 웹 경로 확인 100국, 최종 웹 100국으로 총 568건이다. 각 범주의 목적과 시작 조건이 달라 하나의 승률로 합산하지 않는다. 이 집계에 테스트의 대국은 포함하지 않았다. 코드와 요약은 로컬 `codex/winrate-lab`에 커밋하고, 원격 push·배포는 수행하지 않았다.

## 재현 명령

```powershell
# 서버용 .env와 별도 실험 DB를 준비한 본 작업 폴더 기준
node scripts/winrate-server.mjs

# 별도 터미널: 완료된 조합은 재사용하는 144국 선별
node scripts/winrate-campaign.mjs --stage screening --games 4

# 고정 상대에 대해 준비한 세 후보를 각각 4국 비교
node scripts/winrate-campaign.mjs --stage candidates --b azero-v2 --games 4

# 웹 100국: 같은 label로 재실행하면 기존 requestId/배치에서 재개
node scripts/winrate-web.mjs greedy-v1 random-v1 pipeline-check

# 최종 후보의 실제 웹 100국: 같은 label은 기존 배치를 재검증
node scripts/winrate-web.mjs lab-neural-v2 azero-v2 final-confirmation

node scripts/finish-winrate-campaign.mjs

# 진행 중인 배치를 마친 뒤 서버 정상 종료
node scripts/winrate-server.mjs stop
```

연속 실행 중 동일 label을 다른 조합에 재사용하면 거부한다. 세션 파일은 Git에서 제외되는 `data/`에 보관하고 보고서에는 포함하지 않는다.
