# AlphaZero Gumbel-trained

`azero-v2`는 Gumbel 방식의 자기 대국으로 정책·가치 MLP를 추가 학습한 모델이다. 실제 착수는 `azero-core.mjs`의 PUCT 몬테카를로 트리 탐색을 기본 800회 실행한 뒤 방문 수가 가장 많은 후보를 반환한다. Gumbel 방식은 학습에 사용한다.

진입점은 `azero-v2.mjs`, 배포 가중치는 `azero-v2.bin`이다. 배포 가중치나 모델 설정을 바꿀 때는 [모델 등록 가이드](../model.md)에 따라 새 버전을 등록한다.

탐색 코어의 절대 수 제한은 256수다. 웹 모델 대전의 심판도 256수에서 무승부를 판정한다. 모델 엔진에서 기존 이력이 256수에 도달하면 **현재 국면으로 새 분석**을 사용해 배치와 포로를 유지한 채 이력을 새로 시작할 수 있다.

알고리즘 비교와 최신 대전 결과는 [모델 보고서](../docs/models_report.md)의 M06을 참고한다.
