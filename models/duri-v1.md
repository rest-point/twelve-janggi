# Duri Tactical Solver

`duri-v1`은 즉시 이길 수 있는 수와 상대의 즉시 승리 위협을 먼저 확인한 뒤 MCTS-Solver로 수를 고른다. 신경망의 정책·가치로 탐색 순서를 정하고, 실제 종국에서 확정된 승·무·패를 탐색 경로에 전파한다. 반복 이력은 경로마다 관리한다.

Duri는 AlphaZero의 초기 신경망 가중치를 그대로 사용한다. 해당 가중치 파일은 Duri의 실행 의존성이며 별도의 AlphaZero v2 가중치로 교체하지 않는다. 기본 한도는 6,000회 시뮬레이션, 6,001노드, 내부 시간 57초다. 바깥 시간 제한은 서버 실행기가 적용한다.

알고리즘 비교와 최신 대전 결과는 [모델 보고서](../docs/models_report.md)의 M10을 참고한다.
