# Duri · V1 Tactical Solver

`duri-v1`은 AlphaZero v1과 대전하기 위한 별도 모델이다. 기존 **AlphaZero v1 신경망 가중치**(`azero-v1.bin`)를 그대로 재사용하고, 직접 구현한 전술 선검사와 MCTS-Solver 탐색을 결합한다. 학습을 새로 수행하지 않았으며 독립적으로 학습된 신경망이 아니다. **AlphaZero v2 가중치나 v2 모델 실행 파일은 사용하지 않는다.** 기존 SolJang의 검색 코드 `soljang-search-v1.mjs`는 공유하지만 SolJang 모델 엔트리와 v2 가중치는 읽지 않는다.

합법수에서 즉시 승리와 상대의 즉시 승리 위협을 먼저 검사한다. 이후 신경망 정책·가치 추정으로 탐색하고 실제 종국에서 확인된 승·무·패만 탐색 트리 위로 전파한다. 반복 이력은 경로별로 유지한다. 기본 한도는 시뮬레이션 6,000회, 트리 6,001노드, 내부 시간 57초다. 수당 요청 시간의 5%(100~3,000ms)를 통신 여유로 남기며, 한도에 먼저 도달하거나 확정 결과를 찾으면 일찍 반환한다. 최종 시간 제한은 서버 실행기가 적용한다. 메모리·시간의 하드 실시간 보장은 아니다.

서버를 시작하면 **Duri · V1 Tactical Solver**를 선택할 수 있다. 평가 예시:

```sh
node scripts/evaluate.mjs --a duri-v1 --b azero-v1 --games 40 --concurrency 2 --opening-plies 4 --move-ms 60000 --max-plies 256 --seed 20261118
```

## 실측과 해석

Apple M4, 메모리 16GB, Node.js v26.5.0. 모든 경기는 양쪽에 수당 60초, 최대 256수로 진행했고 스케줄·설정 해시·기보·시간·집계를 `scripts/verify-replays.mjs`로 전수 확인했다. 아래 승/무/패는 Duri 기준이다. 득점률은 `(승 + 무승부/2) / 대국 수`이며 승률과 다르다. 각 시작 국면에서 양 모델의 진영을 바꿔 대국하므로 대국 수만큼 독립적인 표본은 아니다.

네 실행 모두 양쪽 모델 실행 오류가 없었다. 합계 148국에서 60승 55무 33패, 승률 40.54%, 득점률 59.12%다. 첫 세 실행은 동시 2국, 마지막은 동시 3국이다. 6,000회 설정은 위 결과를 보기 전에 정했고 별도 seed를 확인한 뒤에도 변경하지 않았다. AlphaZero v1 상대에만 국한된 관찰이며, 모든 시작 국면이나 다른 모델에 대한 우위를 뜻하지 않는다. 원본 설정·결과는 각 `artifacts/<run-id>/`에 저장되며 Git으로 공유되지 않을 수 있다.

SolJang과 같은 오프닝(seed `20261203`)으로 AlphaZero v1 상대 24국씩 추가 비교했다. SolJang은 10승 7무 7패(승률 41.67%, 득점률 56.25%), Duri는 8승 9무 7패(승률 33.33%, 득점률 52.08%)였다. 양쪽 실행 오류는 없었고 기보·기한·집계를 전수 검증했다. 이 작은 표본에서는 SolJang이 앞섰지만 우위가 확정된 것은 아니다. SolJang은 팀원의 AlphaZero v2 가중치를 사용하므로, v2를 제외해 달라는 요청에 따라 GitHub에는 Duri를 등록한다. Duri를 더 높은 승률의 모델로 주장하지 않는다.

40국 실행에서 Duri의 착수시간 중앙값은 약 654ms, p95는 약 830ms였다. 별도의 첫 국면 단일 Node 프로세스 표본에서는 약 800ms, 최대 RSS 약 86MiB, 반환 시 heap 약 22MiB였다. 조건과 부하에 따른 표본이며 최대 메모리 보장은 아니다. 실행 artifact SHA-256: `b7f290242e129f508df86d0574d820c2755eb2cf1412bf3c3121f4ff0764f377`.
